# Vendinha Solidária

## Sobre o sistema

A **Vendinha Solidária** é uma plataforma para gestão de estoque e realização de pedidos de produtos.

O sistema permite controlar produtos, entradas, saídas, estoque, documentos e usuários, além de oferecer um portal onde os compradores podem selecionar produtos e gerar um link de pagamento.

Todo o processo é registrado automaticamente, garantindo maior organização e controle das movimentações.

---

# Funcionalidades

## Cadastro de Produtos

Os produtos disponíveis para venda são cadastrados no sistema.

Cada produto pode possuir:

- Nome
- Preço
- Imagem
- Informações adicionais

---

## Cadastro de Locais

Os locais representam onde os produtos estão armazenados.

Exemplos:

- Depósito
- Almoxarifado
- Estoque principal

Cada local possui:

- Nome
- Sigla

---

## Entrada de Produtos

Quando novos produtos chegam ao estoque, é realizado um registro de entrada.

Informações registradas:

- Produto
- Quantidade
- Local de armazenamento
- Data da movimentação

Ao registrar uma entrada, o estoque é atualizado automaticamente.

---

## Portal de Compras

Os compradores podem acessar a plataforma para realizar seus pedidos.

### Fluxo de compra

1. O comprador informa seu nome.
2. Seleciona os produtos desejados.
3. Define as quantidades.
4. O sistema calcula o valor total do pedido.
5. É gerado um link de pagamento.
6. Após a confirmação do pagamento, a venda é processada.

---

## Saída de Produtos

Após a confirmação da compra, o sistema registra automaticamente a saída dos produtos do estoque.

São registrados:

- Comprador
- Produtos adquiridos
- Quantidades
- Valor da compra
- Data da movimentação

O estoque é atualizado automaticamente para refletir a quantidade restante disponível.

---

## Controle de Estoque

O sistema mantém um controle atualizado da quantidade disponível de cada produto.

As quantidades são recalculadas automaticamente com base nas entradas e saídas registradas.

Exemplo:

| Produto | Local | Quantidade |
|----------|----------|----------|
| Chocolate | Depósito | 100 |
| Arroz | Estoque Principal | 50 |

---

## Gestão de Documentos

O sistema permite armazenar documentos relacionados às operações.

Exemplos:

- Notas fiscais
- Comprovantes
- Documentos administrativos

Cada registro pode conter:

- Descrição
- Tipo
- Valor
- Data
- Arquivo PDF

Os arquivos são armazenados em nuvem para facilitar o acesso e a organização.

---

## Gestão de Usuários

O acesso administrativo é protegido por autenticação.

Cada usuário possui:

- E-mail
- Senha

Somente usuários autorizados podem acessar as áreas administrativas do sistema.

---

# Fluxo Operacional

## Configuração Inicial

1. Cadastrar locais de armazenamento.
2. Cadastrar produtos.

## Operação Diária

1. Registrar entradas de produtos.
2. Receber pedidos dos compradores.
3. Gerar links de pagamento.
4. Confirmar pagamentos.
5. Registrar saídas automaticamente.
6. Consultar estoque.

## Controle Administrativo

1. Consultar movimentações.
2. Consultar documentos.
3. Gerenciar usuários.
4. Acompanhar estoque.

---

# Benefícios

- Controle centralizado do estoque.
- Registro automático de movimentações.
- Processo simplificado de compra.
- Integração com pagamentos.
- Histórico completo das operações.
- Armazenamento digital de documentos.
- Acesso seguro por autenticação.
